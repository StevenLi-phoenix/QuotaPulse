# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

QuotaPulse: macOS menu-bar app + iOS/watchOS apps + widgets showing AI-provider rate-limit windows/balances (Claude, Codex, DeepSeek, OpenCode, GLM, Grok Bot) with burn-rate forecasts. README.md has the full feature/privacy/known-limits write-up; `docs/research.md` has provider endpoints and design decisions (Chinese).

## Commands

```bash
cd QuotaCore && swift test                          # core logic tests (Swift Testing/XCTest, fixtures in Tests/QuotaCoreTests/Fixtures)
cd QuotaCore && swift test --filter <TestName>      # single test / suite
cd QuotaUI && swift test                            # menu-line view-model tests
cd QuotaUI && swift run WidgetRender ../docs/screenshots   # render widget/complication/menu-panel/overview PNGs from real views (headless visual check)
QP_SNAPSHOT=<snapshot.json> swift run WidgetRender /tmp/out   # overview.png from a real snapshot (copy snapshot.json + samples.json out of the group container)
xcodegen generate                                   # project.yml → QuotaPulse.xcodeproj (xcodeproj is generated, not committed; xcodegen at ../tools/xcodegen/bin/xcodegen, PATH, or /opt/homebrew/bin)
xcodebuild -scheme QuotaPulse-macOS -destination 'platform=macOS' build
xcodebuild -scheme QuotaPulse-iOS -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
python3 scripts/gen-strings.py                      # regenerate en / zh-Hans string catalogs (translations in scripts/zh-Hans.json)
python3 scripts/gen-strings.py --verify <Intermediates dirs>   # also check keys against compiler .stringsdata (after a build)
scripts/install.sh                                  # Release build → ~/Applications/QuotaPulse.app and launch (stops the old instance by PID)
log stream --predicate 'subsystem == "app.lishuyu.quotapulse"'   # runtime logs (secrets redacted)
```

No linter is configured. Swift 6 strict concurrency (`complete`) everywhere; deployment min is macOS/iOS/watchOS 26.

## Architecture

- **`QuotaCore`** (SwiftPM, no UI, platform-agnostic): everything that matters.
  - `Providers/` — one `UsageProvider` per service, each with a `ProviderDescriptor` (id, `ProviderInfo`, default-on, takes-API-key). Registered in `ProviderRegistry.all()`. Adding a provider = one file + registry entry; the engine stamps `info` on every snapshot, so older UIs/other devices render it without code changes (see README "Adding a provider").
  - `Credentials/` — reads credentials from where CLIs keep them (Claude Keychain/`~/.claude/.credentials.json`, `~/.codex/auth.json`, Grok Bot session); `SecretStore` abstracts API keys (Keychain, iCloud-synced).
  - `Store/QuotaEngine` — polling loop, backoff, history persistence; `Forecast/ForecastEngine` — least-squares burn rate, exhaustion time, pace.
  - **Three ways numbers reach a device**, merged by "newest snapshot wins": iCloud/CloudKit (`Cloud/`: Mac publishes, iPhone/Watch read; production environment only), the Mac's authenticated HTTP **hub** (`Hub/`, port 48422), and an optional **gateway** (`Gateway/`, enabled by `gateway.json`, replaces local OpenCode/DeepSeek keys and receives reports). `Models/Models.swift` holds the shared `QuotaSnapshot` wire types — hub/iCloud payloads must stay decodable by older clients (hence `providers=all` gating and self-describing provider info).
  - `Telemetry/` — device log shipping to the hub.
- **`QuotaUI`** (SwiftPM): shared SwiftUI components, widget views, menu summary lines, the menu-bar item (`MenuBarStatus` builds one bar per provider from the snapshot: tightest window, left %, alert (tooltip/log only) / stale / no-data; `MenuBarImage` draws them as text-free level meters, height = left like a battery, red stub when used up, faded when stale, colour = `ProviderInfo.brandHex`, which `ProviderInfo.defaultHex(for:)` derives from the id when a provider publishes none; `WidgetRender` draws `menubar-{dark,light}.png`) and the menu-bar group view (`MenuGroupView`, so `WidgetRender` can draw the real panel to `menu-panel-{light,dark}.png` for headless contrast checks), localized strings (`Resources/Localizable.xcstrings`).
- **App targets** declared in `project.yml`: `macOS/App` (+ `macOS/Widget`, Sparkle updater), `iOS/App` (+ widget, UI tests), `watchOS/App` (+ complications). `Shared/Resources` holds app icon and strings.
- Localization: `.xcstrings` catalogs are generated by `scripts/gen-strings.py`; edit the script / `zh-Hans.json`, not the catalogs. `zh-Hans.json` is keyed by the source literal (`Resets in \(…)`); the script writes the runtime key (`Resets in %@`, `%lld` for Int expressions, literal `%` doubled), so an interpolation of a new Int-typed shape may need `INT_EXPR` updated — `--verify` catches it. Window titles and provider subtitles published by QuotaCore are looked up at runtime (`UsageWindow.localizedTitle`, `localizedSubtitle`), so the script also collects their literals.
- Colour encoding: brand colour = which provider (glyph, border, sparkline); bar length / ring arc = how much is used; `UsageLevel(window:forecast:)` = health (percent, bar, ring colour). The overview grid is `MasonryLayout` (QuotaUI).

## Releasing

A pushed `v<x.y.z>` tag is the release; pushes to `main` release nothing. Put changes under `[Unreleased]` in `CHANGELOG.md` (Keep a Changelog, one-liners), push, then `scripts/release.sh auto|patch|minor|major|x.y.z` — it bumps `MARKETING_VERSION`/`CURRENT_PROJECT_VERSION` in `project.yml`, rolls the changelog, commits `chore(release): <v>`, tags and pushes atomically. The tag triggers `.github/workflows/release.yml` (tests → `scripts/publish.sh`: archive, Developer ID sign, notarize, Sparkle appcast). `publish.sh` refuses unless the tag is HEAD, matches `project.yml`, is on `main`, and the build number exceeds the feed's.

## Gotchas

- CloudKit schema changes (new record type/field) must be made in the Development schema and deployed to Production in CloudKit Console; builds can't create schema in Production.
- Claude's `/api/oauth/usage` is heavily rate-limited (backoff up to 30 min); QuotaPulse's own token refresher is off by default so Claude Code's refresh token isn't rotated. Claude windows are *cleared* at `resets_at`, not rolled forward (unlike Codex).
- Unsigned dev builds have no iCloud entitlement, so sync is off. Widgets on real devices need the App Group `group.app.lishuyu.quotapulse`.
- Commit messages: `<type>: <description>` (feat, fix, refactor, docs, test, chore, perf, ci).
